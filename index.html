How carton depth changes the estimate +

A ±10% change in nominal carton depths changes how many whole boxes fit. These supported one-missing models span 276–336 boxes. This tests one assumption; it is not a bound on every possible pallet layout.

Read the dimensional assumptions +

The model assumes a 1200 × 1000 × 162 mm pallet and ten physical courses. Median model carton dimensions are about 142×160×142 mm, with substantial fitted variation. All four scenarios pass static support and ten-second rigid-body gravity checks. Rear occupancy remains assumed.

The model approximates staggered boundaries and exposes small fragments of inferred fill through fitting gaps. Source texture helps correspondence; the neutral view and top residuals reveal where geometry differs.

WHERE THE EVIDENCE ENDS

Precision includes knowing
what is still unknown.

The model gives a useful conditional estimate: about 320 boxes. Its 315–318 missing-box interval assumes one packing; the 276–336 depth sweep shows how dimensions can move the answer. Neither is a measured inventory or a statistical confidence interval.
